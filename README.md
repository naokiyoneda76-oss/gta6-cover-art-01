Vice Panels is an offline web app that turns your own photos into bold multi-panel cover art in a Vice City sunset / neon style: pick a panel layout, drop a photo into each panel, crop and position it, add a heavy caption, choose a colour grade, and export a PNG at 1080 x 1080, 1080 x 1350 or 1920 x 1080. Everything runs locally in the browser — photos are never uploaded, there is no build step and no network request. Lettering uses the bundled Noto Sans (SIL Open Font License 1.1, see app/fonts/OFL-1.1.txt); the design, name and artwork treatment are original.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
# or package the entry (app/, screenshots/, dossier.json):
MAKEFUN_OUTPUT_DIR=out node main.ts
```
